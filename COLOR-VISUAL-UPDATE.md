# CreditCore v2.3 — Color & Visualization Update

This release keeps the enterprise dark/light theme but removes the monochrome feel from analytical visualizations.

## Updated

- Assessment Trend: blue line with visible points and grid.
- Risk Grade Distribution: purple bars.
- Decision Distribution: semantic green / amber / red / blue slices.
- Architecture layers: subtle blue / purple / green visual grouping.
- Added semantic visualization tokens for success, warning, danger, information, and analytical series.
- Existing backend, REST contracts, scoring formula, lifecycle, Prisma/PostgreSQL roadmap, and API routing are unchanged.

## Visual language

- Blue: API / information / traffic
- Green: approved / healthy / success
- Amber: manual review / warning
- Red: rejected / error
- Purple: scoring / analytics
- Cyan: observability / tracing
